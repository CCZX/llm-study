## 2. 训练循环解决什么问题

一个最小训练 step 包含：

~~~text
输入 batch
  ↓
模型前向得到预测
  ↓
损失函数比较预测与标签
  ↓
自动微分计算梯度
  ↓
优化器更新参数
~~~

代码顺序：

~~~python
optimizer.zero_grad(set_to_none=True)
outputs = model(inputs)
loss = criterion(outputs, targets)
loss.backward()
optimizer.step()
~~~

顺序不是随意的：

- 不清梯度：新梯度会加到旧梯度上
- 不调用 `backward`：参数没有本轮梯度
- 在 `backward` 前 `step`：使用的是旧梯度或空梯度
- 把 `step` 放在 `no_grad` 外手写更新：可能污染计算图；优化器内部已经安全处理

## 3. 回归：MSELoss

模型输出连续数值：

~~~python
from torch import nn

criterion = nn.MSELoss()
~~~

~~~python
predictions = torch.tensor([2.0, 4.0, 5.0])
targets = torch.tensor([1.0, 5.0, 5.0])
loss = criterion(predictions, targets)
~~~

默认 `reduction="mean"`：

~~~text
MSE = [(2-1)² + (4-5)² + (5-5)²] / 3
    = 2/3
~~~

预测和标签 shape 应一致：

~~~text
正确：predictions (batch,), targets (batch,)
正确：predictions (batch, 1), targets (batch, 1)
危险：predictions (batch, 1), targets (batch,)
~~~

最后一种可能因广播而“能运行”，但比较出 `(batch, batch)` 的错误结果。训练前必须断言：

~~~python
assert predictions.shape == targets.shape
~~~

## 4. 多分类：CrossEntropyLoss

模型输出：

~~~text
logits:  (batch, num_classes)，float
targets: (batch,)，long
~~~

~~~python
criterion = nn.CrossEntropyLoss()
logits = model(inputs)
loss = criterion(logits, targets)
~~~

不要提前做：

~~~python
probabilities = torch.softmax(logits, dim=1)
loss = criterion(probabilities, targets)  # 错误用法
~~~

`CrossEntropyLoss` 内部等价于数值稳定的：

~~~text
LogSoftmax + Negative Log Likelihood
~~~

传 logits 可以避免先算概率时的数值损失。

类别标签示例：

~~~python
targets = torch.tensor([2, 0, 1], dtype=torch.long)
~~~

通常不需要 one-hot：

~~~text
正确标签：[2, 0, 1]
不是：    [[0,0,1], [1,0,0], [0,1,0]]
~~~

## 5. 二分类：BCEWithLogitsLoss

二分类可以使用一个 logit：

~~~text
logits:  (batch,) 或 (batch, 1)，float
targets: 与 logits 同 shape，float，值通常为 0 或 1
~~~

~~~python
criterion = nn.BCEWithLogitsLoss()
loss = criterion(logits, targets)
~~~

不要先调用 Sigmoid。`BCEWithLogitsLoss` 已组合 Sigmoid 和二元交叉熵，并使用数值稳定实现。

预测时才转换概率：

~~~python
probabilities = torch.sigmoid(logits)
predictions = (probabilities >= 0.5).long()
~~~

本阶段文本分类项目也可以使用两个 logits + `CrossEntropyLoss`。两种方案都正确，但输出 shape、标签 dtype 和预测方式必须一致。

## 6. reduction 与整轮统计

常见 reduction：

- `mean`：当前 batch 内平均
- `sum`：当前 batch 内求和
- `none`：返回每个元素的损失

如果每个 batch 大小完全相同，直接平均 batch loss 通常没问题；最后一个 batch 较小时，会产生偏差。

错误：

~~~python
epoch_loss = sum(batch_losses) / len(batch_losses)
~~~

正确的按样本加权：

~~~python
total_loss = 0.0
total_samples = 0

for inputs, targets in data_loader:
    ...
    batch_size = inputs.shape[0]
    total_loss += loss.item() * batch_size
    total_samples += batch_size

epoch_loss = total_loss / total_samples
~~~

如果一个样本包含不同数量的有效 Token，语言模型阶段需要按 token 数加权，而不是按样本数。

## 7. 优化器

### 7.1 SGD

~~~python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.1,
)
~~~

带 Momentum：

~~~python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01,
    momentum=0.9,
)
~~~

### 7.2 AdamW

~~~python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-3,
    weight_decay=1e-2,
)
~~~

初步直觉：

- SGD 更新直接、易分析，对学习率较敏感
- Momentum 使用历史方向减少震荡
- AdamW 为不同参数自适应缩放更新，常作为方便的起点
- 优化器不能修复错误数据、错误损失或错误标签

不要把“Adam 一定比 SGD 好”当作规则。比较时应固定初始化、数据划分和训练预算。

## 8. 一个训练 step

~~~python
def train_step(
    model,
    inputs,
    targets,
    criterion,
    optimizer,
):
    model.train()
    optimizer.zero_grad(set_to_none=True)

    outputs = model(inputs)
    loss = criterion(outputs, targets)

    loss.backward()
    optimizer.step()

    return loss.item()
~~~

这里调用 `model.train()` 是为了让 Dropout、BatchNorm 等模块进入训练行为。今天的简单模型可能看不出区别，第 27 天会专门验证。

## 9. 一个训练 epoch

~~~python
def train_one_epoch(
    model,
    data_loader,
    criterion,
    optimizer,
    device,
):
    model.train()
    total_loss = 0.0
    total_samples = 0

    for inputs, targets in data_loader:
        inputs = inputs.to(device)
        targets = targets.to(device)

        optimizer.zero_grad(set_to_none=True)
        outputs = model(inputs)
        loss = criterion(outputs, targets)
        loss.backward()
        optimizer.step()

        batch_size = inputs.shape[0]
        total_loss += loss.item() * batch_size
        total_samples += batch_size

    return total_loss / total_samples
~~~

不要把带计算图的 `loss` 直接累加到 Python 变量：

~~~python
total_loss += loss  # 可能保留每个 batch 的计算图
~~~

记录统计使用 `loss.item()`。

## 10. 回归完整示例

~~~python
torch.manual_seed(42)

x = torch.linspace(-2, 2, 200).unsqueeze(1)
y = 3.0 * x - 1.0

model = nn.Linear(1, 1)
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)

history = []

for epoch in range(200):
    model.train()
    optimizer.zero_grad(set_to_none=True)
    predictions = model(x)
    loss = criterion(predictions, y)
    loss.backward()
    optimizer.step()
    history.append(loss.item())
~~~

训练后：

~~~python
print(model.weight.item())  # 接近 3
print(model.bias.item())    # 接近 -1
~~~

先训练无噪声数据，确认代码正确，再添加噪声研究泛化。

## 11. 多分类完整示例

~~~python
torch.manual_seed(42)

features = torch.randn(200, 2)
labels = (features[:, 0] + features[:, 1] > 0).long()

model = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),
    nn.Linear(8, 2),
)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-2)

for epoch in range(200):
    model.train()
    optimizer.zero_grad(set_to_none=True)
    logits = model(features)
    loss = criterion(logits, labels)
    loss.backward()
    optimizer.step()
~~~

预测类别：

~~~python
with torch.inference_mode():
    logits = model(features)
    predictions = logits.argmax(dim=1)
    accuracy = (predictions == labels).float().mean()
~~~

`argmax` 可以直接作用于 logits；Softmax 不改变最大值所在类别。

## 12. 小 batch 过拟合测试

在正式训练前，选择 16～64 个样本，重复训练到接近零损失或极高准确率。

能通过说明：

- 输入与标签大概率对齐
- 模型有足够容量
- 损失和输出格式大概率正确
- 梯度能到达参数
- 优化器确实更新参数

不能通过时优先检查：

1. 标签是否正确、范围是否合法
2. logits shape 是否为 `(batch, classes)`
3. 参数是否在优化器里
4. 梯度是否为 None 或非有限
5. 学习率是否极端
6. 是否每轮重新创建模型或优化器

小 batch 过拟合通过不代表泛化良好，它是训练管线的单元测试。

## 13. 梯度与参数更新诊断

检查是否有梯度：

~~~python
for name, parameter in model.named_parameters():
    print(name, parameter.grad is None)
~~~

检查梯度有限：

~~~python
for parameter in model.parameters():
    if parameter.grad is not None:
        assert torch.isfinite(parameter.grad).all()
~~~

确认参数真的更新：

~~~python
from copy import deepcopy

before = deepcopy(model.state_dict())
# 执行一个训练 step
after = model.state_dict()

changed = any(
    not torch.equal(before[name], after[name])
    for name in before
)
~~~

## 14. 常见错误

### 14.1 对 logits 先做 Softmax

症状：CrossEntropy 训练变慢或梯度行为异常。

修复：模型直接返回 logits。

### 14.2 标签 dtype 错误

- CrossEntropy 类别编号：`long`
- MSE 回归目标：通常 `float32`
- BCEWithLogits 目标：与 logits 同浮点 dtype

### 14.3 回归 shape 静默广播

`(batch, 1)` 与 `(batch,)` 可能广播成错误的二维比较。显式断言 shape。

### 14.4 忘记 zero_grad

梯度跨 step 累积，除非这是有意实现的梯度累积。

### 14.5 在循环中重建优化器

~~~python
for epoch in range(epochs):
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
~~~

这会丢失 Momentum/Adam 状态。优化器应在训练循环外创建。

### 14.6 只记录最后一个 batch loss

最后 batch 不能代表整轮，应按样本或 token 聚合。

## 15. 自测题

1. `CrossEntropyLoss` 的输入和标签 shape/dtype 是什么？
2. 为什么不能把 Softmax 概率传给 CrossEntropyLoss？
3. 为什么最后一个 batch 较小时不能简单平均 batch loss？
4. `zero_grad` 应放在哪里？
5. 为什么优化器不能每个 epoch 都重建？
6. 小 batch 过拟合测试通过和不通过分别说明什么？

答案：

~~~text
1. logits: (N,C) 浮点；targets: (N,) long。
2. CrossEntropyLoss 已内部执行数值稳定的 LogSoftmax。
3. 每个 batch 的平均值代表不同数量样本，应按样本数加权。
4. 每次需要独立梯度的前向/反向之前。
5. 会丢失 Momentum 或 Adam 的内部状态。
6. 通过说明管线基本可学；不通过说明应先查实现，不应直接扩大训练。
~~~
