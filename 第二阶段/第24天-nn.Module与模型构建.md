## 2. 为什么需要 nn.Module

第一阶段可以用字典保存参数：

~~~python
parameters = {
    "weight": ...,
    "bias": ...,
}
~~~

模型变复杂后，还要解决：

- 哪些 Tensor 是可训练参数
- 如何递归收集子层参数
- 如何把整个模型移动到设备
- 如何切换训练和评估模式
- 如何保存与恢复权重

`nn.Module` 提供统一机制处理这些问题。

## 3. 最小 Module

~~~python
import torch
from torch import nn


class LinearModel(nn.Module):
    def __init__(self, input_dim: int, output_dim: int) -> None:
        super().__init__()
        self.linear = nn.Linear(input_dim, output_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.linear(x)
~~~

创建并调用：

~~~python
model = LinearModel(input_dim=4, output_dim=3)
x = torch.randn(8, 4)
logits = model(x)

print(logits.shape)  # (8, 3)
~~~

### 3.1 为什么调用 model(x)，而不是 model.forward(x)

`model(x)` 会先进入 `nn.Module.__call__`，它负责处理：

- 前向和反向 hook
- 自动混合精度等框架机制
- 再调用你定义的 `forward`

因此应该写：

~~~python
output = model(x)
~~~

而不是直接调用：

~~~python
output = model.forward(x)
~~~

### 3.2 为什么必须调用 super().__init__()

父类初始化会创建模块、参数和 buffer 的内部注册结构。如果遗漏，给 `self.linear` 赋值时通常会报错，或模型无法正常追踪状态。

## 4. nn.Linear 的计算

~~~python
layer = nn.Linear(in_features=4, out_features=3)
~~~

它包含：

~~~text
weight: (3, 4)
bias:   (3,)
~~~

对输入：

~~~text
x:      (batch, 4)
output: (batch, 3)
~~~

计算公式：

~~~text
output = x @ weight.T + bias
~~~

注意 `nn.Linear.weight` 的形状是 `(out_features, in_features)`，与第一阶段常用的 `W: (in_features, out_features)` 相反。

手工对照：

~~~python
x = torch.randn(5, 4)
layer = nn.Linear(4, 3)

module_output = layer(x)
manual_output = x @ layer.weight.T + layer.bias

assert torch.allclose(module_output, manual_output)
~~~

`nn.Linear` 还可以直接处理多维输入，只转换最后一维：

~~~python
x = torch.randn(2, 10, 4)
y = layer(x)
print(y.shape)  # (2, 10, 3)
~~~

## 5. nn.Parameter 与参数注册

`nn.Parameter` 是 Tensor 的子类。把它赋值为 Module 属性时，会被自动注册为可训练参数。

~~~python
class ManualLinear(nn.Module):
    def __init__(self, input_dim: int, output_dim: int) -> None:
        super().__init__()
        self.weight = nn.Parameter(torch.randn(input_dim, output_dim))
        self.bias = nn.Parameter(torch.zeros(output_dim))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return x @ self.weight + self.bias
~~~

查看参数：

~~~python
model = ManualLinear(4, 3)

for name, parameter in model.named_parameters():
    print(name, parameter.shape, parameter.requires_grad)
~~~

普通 Tensor 属性不会自动成为参数：

~~~python
class Example(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.trainable = nn.Parameter(torch.ones(3))
        self.not_trainable = torch.ones(3)
~~~

如果某个非参数 Tensor 需要随模型一起移动设备、保存和加载，应注册为 buffer：

~~~python
self.register_buffer("running_total", torch.zeros(1))
~~~

BatchNorm 的运行均值就是典型 buffer。

## 6. 构建两层 MLP

~~~python
class MLP(nn.Module):
    def __init__(
        self,
        input_dim: int,
        hidden_dim: int,
        output_dim: int,
    ) -> None:
        super().__init__()
        self.linear1 = nn.Linear(input_dim, hidden_dim)
        self.activation = nn.ReLU()
        self.linear2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        hidden = self.activation(self.linear1(x))
        return self.linear2(hidden)
~~~

形状：

~~~text
x         (batch, input_dim)
linear1   (batch, hidden_dim)
ReLU      (batch, hidden_dim)
linear2   (batch, output_dim)
~~~

模型最后返回 logits，不在 `forward` 中做 Softmax。后续的 `CrossEntropyLoss` 会在数值更稳定的实现中处理 LogSoftmax 和 NLLLoss。

## 7. nn.Sequential

顺序结构可以写成：

~~~python
model = nn.Sequential(
    nn.Linear(4, 16),
    nn.ReLU(),
    nn.Linear(16, 3),
)
~~~

适合：

- 单一路径
- 每层只有一个主要输入和输出
- 不需要保存多个中间值

不适合：

- 残差连接
- 多分支或多输入
- 需要 mask、hidden state 等额外参数
- 复杂控制流

学习 Transformer 时会频繁使用自定义 `forward`，所以两种方式都要掌握。

## 8. 普通 list 与 ModuleList

错误示例：

~~~python
class BadStack(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.layers = [nn.Linear(4, 4), nn.Linear(4, 4)]
~~~

普通 Python list 中的层不会被 Module 递归注册：

~~~python
model = BadStack()
print(sum(p.numel() for p in model.parameters()))  # 可能为 0
~~~

正确方式：

~~~python
class GoodStack(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.layers = nn.ModuleList([
            nn.Linear(4, 4),
            nn.Linear(4, 4),
        ])

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        for layer in self.layers:
            x = torch.relu(layer(x))
        return x
~~~

类似容器：

- `nn.ModuleList`：保存子模块列表
- `nn.ModuleDict`：保存子模块字典
- `nn.ParameterList`：保存参数列表
- `nn.ParameterDict`：保存参数字典

## 9. 查看模型与参数

~~~python
model = MLP(4, 16, 3)
print(model)
~~~

遍历所有参数：

~~~python
for name, parameter in model.named_parameters():
    print(
        name,
        tuple(parameter.shape),
        parameter.numel(),
        parameter.requires_grad,
    )
~~~

统计可训练参数：

~~~python
trainable_count = sum(
    parameter.numel()
    for parameter in model.parameters()
    if parameter.requires_grad
)
~~~

对于 `MLP(4, 16, 3)`：

~~~text
第一层：4×16 + 16 = 80
第二层：16×3 + 3 = 51
总计：131
~~~

参数量不仅影响表达能力，也影响内存、计算量和过拟合风险。

## 10. state_dict

~~~python
model = MLP(4, 16, 3)
state = model.state_dict()

for name, tensor in state.items():
    print(name, tensor.shape)
~~~

典型键：

~~~text
linear1.weight
linear1.bias
linear2.weight
linear2.bias
~~~

`state_dict` 保存参数和持久 buffer，不保存 Python 类定义。加载时必须先创建兼容结构：

~~~python
restored = MLP(4, 16, 3)
restored.load_state_dict(state)
~~~

保存到文件：

~~~python
torch.save(model.state_dict(), "model.pt")
~~~

加载：

~~~python
state = torch.load("model.pt", map_location="cpu", weights_only=True)
model.load_state_dict(state)
~~~

不要把 `state_dict()` 的返回值直接当“冻结快照”长期留在内存中，因为其中 Tensor 可能仍引用模型存储。需要内存快照时使用深拷贝：

~~~python
from copy import deepcopy

best_state = deepcopy(model.state_dict())
~~~

## 11. 参数初始化

PyTorch 各层已有默认初始化。为了理解初始化和做可控实验，可以显式初始化：

~~~python
def initialize_module(module: nn.Module) -> None:
    if isinstance(module, nn.Linear):
        nn.init.kaiming_normal_(
            module.weight,
            mode="fan_in",
            nonlinearity="relu",
        )
        if module.bias is not None:
            nn.init.zeros_(module.bias)


model.apply(initialize_module)
~~~

注意：

- 使用 ReLU 时常见 He/Kaiming 初始化
- 使用 Tanh/Sigmoid 时常见 Xavier 初始化
- 最后一层不一定使用与隐藏层完全相同的初始化
- 初始化是实验的一部分，不要盲目覆盖预训练权重

固定随机种子要在创建模型前：

~~~python
torch.manual_seed(42)
model = MLP(4, 16, 3)
~~~

## 12. 设备迁移

~~~python
device = torch.device("cpu")
model = MLP(4, 16, 3).to(device)
x = torch.randn(8, 4, device=device)
logits = model(x)
~~~

`model.to(device)` 会递归移动：

- 注册的参数
- 注册的 buffer
- 注册的子模块

它不会自动移动：

- 普通 Python list 中未注册的层
- 没有注册为 buffer 的普通 Tensor 属性
- 输入数据

这也是正确参数注册的重要原因。

## 13. batch 无关的 forward

好的模型不应该硬编码 batch size：

~~~python
class Classifier(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(4, 8),
            nn.ReLU(),
            nn.Linear(8, 3),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.layers(x)
~~~

以下输入都应工作：

~~~python
model(torch.randn(1, 4)).shape   # (1, 3)
model(torch.randn(7, 4)).shape   # (7, 3)
model(torch.randn(2, 5, 4)).shape  # (2, 5, 3)
~~~

不要在 forward 中写：

~~~python
x = x.view(32, -1)
~~~

应使用：

~~~python
x = x.reshape(x.shape[0], -1)
~~~

## 14. 常见错误

### 14.1 忘记 super().__init__()

症状：赋值子模块时报错，或注册机制异常。

### 14.2 把层放在普通 list

症状：`model.parameters()` 中看不到这些层，优化器不会更新它们，`model.to(device)` 也不会移动它们。

### 14.3 在 forward 中创建可训练层

~~~python
def forward(self, x):
    layer = nn.Linear(4, 3)
    return layer(x)
~~~

每次前向都会创建新参数，优化器无法持续更新同一组权重。层应在 `__init__` 中创建。

### 14.4 把 Softmax 放进分类模型

训练时通常让模型返回 logits，把数值稳定的概率处理交给 `CrossEntropyLoss`。

### 14.5 用错误结构加载 state_dict

输入维度、隐藏维度或输出类别数不一致会导致 shape mismatch。必须保存模型配置。

2. 为什么模型应使用 `model(x)` 而不是 `model.forward(x)`？
3. 普通 Tensor、Parameter 和 buffer 有什么区别？
4. 为什么普通 list 里的层可能不被训练？
5. `state_dict` 是否包含模型类定义？
6. 为什么分类模型通常返回 logits？
7. 如何统计可训练参数总数？

答案：

~~~text
1. (3, 4)
2. model(x) 会经过 Module 的调用机制和 hooks。
3. Parameter 可训练且注册；buffer 不训练但随模型保存和迁移；普通 Tensor 默认都不会。
4. 普通 list 不触发 Module 的递归注册。
5. 不包含，需要先重新创建兼容模型结构。
6. CrossEntropyLoss 直接接收 logits，内部实现更数值稳定。
7. sum(p.numel() for p in model.parameters() if p.requires_grad)
~~~
