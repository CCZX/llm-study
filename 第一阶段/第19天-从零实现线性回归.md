## 7. 线性模型

```text
y_hat = X @ w + b
```

形状：

```text
X      (N, D)
w      (D,)
b      ()
y_hat  (N,)
```

```python
def predict(x, weight, bias):
    return x @ weight + bias
```

初始化：

```python
weight = np.zeros(x_train.shape[1], dtype=np.float64)
bias = 0.0
```

线性回归可以使用零初始化，因为它没有隐藏单元之间的对称性问题。

## 8. MSE 与 RMSE

```python
def mse(y_true, y_pred):
    return float(np.mean((y_pred - y_true) ** 2))

def rmse(y_true, y_pred):
    return float(np.sqrt(mse(y_true, y_pred)))
```

训练使用 MSE，因为梯度形式简单；报告使用 RMSE，因为单位与质量评分一致。

## 9. 解析梯度

```text
errors = y_hat - y

dL/dw = (2/N) Xᵀ @ errors
dL/db = 2 mean(errors)
```

```python
def gradients(x, y, weight, bias):
    predictions = predict(x, weight, bias)
    errors = predictions - y

    grad_weight = (2.0 / len(x)) * (x.T @ errors)
    grad_bias = 2.0 * errors.mean()
    return grad_weight, float(grad_bias)
```

每次实现后都检查：

```python
assert grad_weight.shape == weight.shape
assert np.ndim(grad_bias) == 0
assert np.isfinite(grad_weight).all()
assert np.isfinite(grad_bias)
```

## 10. 批量梯度下降训练循环

```python
def train(
    x_train,
    y_train,
    x_valid,
    y_valid,
    learning_rate=0.05,
    epochs=1000,
):
    weight = np.zeros(x_train.shape[1], dtype=np.float64)
    bias = 0.0
    history = {"train_mse": [], "valid_mse": []}

    for epoch in range(epochs):
        grad_weight, grad_bias = gradients(x_train, y_train, weight, bias)

        weight -= learning_rate * grad_weight
        bias -= learning_rate * grad_bias

        train_predictions = predict(x_train, weight, bias)
        valid_predictions = predict(x_valid, weight, bias)
        history["train_mse"].append(mse(y_train, train_predictions))
        history["valid_mse"].append(mse(y_valid, valid_predictions))

    return weight, bias, history
```

这是全批量梯度下降：每次更新使用全部训练样本。后续 PyTorch 阶段会学习 mini-batch。

    positive = weight.copy()
    negative = weight.copy()

## 17. 常见故障

### 损失不下降

- 检查梯度符号和 `2/N`。
- 检查参数是否真的更新。
- 检查 `X`、`y` 是否对应。
- 检查学习率是否太小。

### 损失变成 NaN 或急剧上升

- 降低学习率。
- 确认特征已标准化。
- 检查是否存在 `NaN`、`inf`。

### 训练很好但验证较差

- 检查数据划分和分布。
- 检查是否泄漏。
- 检查训练轮数和异常样本。

### 模型不如基线

- 优先怀疑实现、数据和评测流程。
- 再考虑线性模型表达能力不足。
