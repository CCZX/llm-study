## 1. 网络结构

```text
输入 X
  ↓
Linear: Z1 = X @ W1 + b1
  ↓
ReLU: H = max(0, Z1)
  ↓
Linear: logits = H @ W2 + b2
  ↓
Softmax + Cross Entropy
```

这是一个只有一个隐藏层的两层神经网络。“两层”通常指两个带参数的 Linear 层，ReLU 不单独计为参数层。

## 2. 形状设计

设：

```text
N：样本数
D：输入特征数
H：隐藏单元数
C：类别数
```

| 变量 | 形状 |
| --- | --- |
| `X` | `(N, D)` |
| `W1` | `(D, H)` |
| `b1` | `(H,)` |
| `Z1` | `(N, H)` |
| `hidden` | `(N, H)` |
| `W2` | `(H, C)` |
| `b2` | `(C,)` |
| `logits` | `(N, C)` |
| `probabilities` | `(N, C)` |

实现每一步后都用断言检查形状。反向传播中的每个参数梯度必须与对应参数形状完全相同。

## 3. 为什么需要隐藏层和激活函数

连续两个没有激活函数的线性层：

```text
X @ W1 @ W2 = X @ (W1 @ W2)
```

仍然等价于一个线性层，无法学习非线性边界。

加入 ReLU：

```text
ReLU(z) = max(0, z)
```

不同样本会激活不同隐藏单元，整个输入空间被分成多个线性区域，网络可以组合出非线性决策边界。

XOR 是经典例子：单个线性分类器无法用一条直线正确分开四个点，带隐藏层的网络可以。

## 4. ReLU

```python
def relu(x):
    return np.maximum(x, 0.0)
```

导数：

```text
z > 0：dReLU/dz = 1
z < 0：dReLU/dz = 0
z = 0：数学上不可导，工程中通常约定为 0
```

```python
def relu_gradient(x):
    return (x > 0).astype(np.float64)
```

如果某个单元对所有样本都长期输出负数，它的梯度可能一直为 0，这称为“死亡 ReLU”。过大学习率和不合适初始化会增加风险。

## 5. 为什么不能把所有权重初始化为零

如果隐藏层所有单元拥有相同初始权重，它们会得到完全相同的输出和梯度，之后仍保持相同，等于只使用一个隐藏单元。

因此需要随机初始化来打破对称性。偏置可以初始化为零。

ReLU 常使用 He 初始化：

```python
rng = np.random.default_rng(seed)
w1 = rng.standard_normal((input_dim, hidden_dim)) * np.sqrt(2.0 / input_dim)
w2 = rng.standard_normal((hidden_dim, output_dim)) * np.sqrt(2.0 / hidden_dim)
b1 = np.zeros(hidden_dim)
b2 = np.zeros(output_dim)
```

缩放可以避免层间信号方差快速变大或变小。

## 6. 前向传播

```python
def forward(x, parameters):
    z1 = x @ parameters["w1"] + parameters["b1"]
    hidden = np.maximum(z1, 0.0)
    logits = hidden @ parameters["w2"] + parameters["b2"]

    cache = {
        "x": x,
        "z1": z1,
        "hidden": hidden,
    }
    return logits, cache
```

`cache` 保存反向传播需要的中间值。不要为了省几行代码在反向传播中随意重新计算，否则容易使用错误参数或错误数据。

## 7. Softmax 和交叉熵

```python
shifted = logits - logits.max(axis=-1, keepdims=True)
exp_logits = np.exp(shifted)
probabilities = exp_logits / exp_logits.sum(axis=-1, keepdims=True)
```

类别编号交叉熵：

```python
correct = probabilities[np.arange(len(labels)), labels]
loss = -np.log(np.clip(correct, 1e-12, 1.0)).mean()
```

## 8. 反向传播总览

前向：

```text
X → Z1 → hidden → logits → loss
```

反向：

```text
loss → dlogits → dW2/db2 → dhidden → dZ1 → dW1/db1
```

每一步把上游梯度乘以当前操作的局部导数。

## 9. 输出层梯度

Softmax 与交叉熵组合：

```python
targets = np.eye(class_count)[labels]
dlogits = (probabilities - targets) / len(x)
```

第二层：

```text
logits = hidden @ W2 + b2
```

```python
grad_w2 = hidden.T @ dlogits
grad_b2 = dlogits.sum(axis=0)
grad_hidden = dlogits @ w2.T
```

形状：

```text
hidden.T     (H, N)
dlogits      (N, C)
grad_w2      (H, C)
grad_hidden  (N, H)
```

## 10. 隐藏层梯度

通过 ReLU：

```python
grad_z1 = grad_hidden * (z1 > 0)
```

第一层：

```text
Z1 = X @ W1 + b1
```

```python
grad_w1 = x.T @ grad_z1
grad_b1 = grad_z1.sum(axis=0)
```

完整梯度字典：

```python
gradients = {
    "w1": grad_w1,
    "b1": grad_b1,
    "w2": grad_w2,
    "b2": grad_b2,
}
```

## 11. 完整损失与梯度函数

```python
def loss_and_gradients(x, labels, parameters):
    logits, cache = forward(x, parameters)
    probabilities = softmax(logits)

    correct = probabilities[np.arange(len(labels)), labels]
    loss = float(-np.log(np.clip(correct, 1e-12, 1.0)).mean())

    targets = np.eye(logits.shape[1])[labels]
    grad_logits = (probabilities - targets) / len(x)

    grad_w2 = cache["hidden"].T @ grad_logits
    grad_b2 = grad_logits.sum(axis=0)

    grad_hidden = grad_logits @ parameters["w2"].T
    grad_z1 = grad_hidden * (cache["z1"] > 0)

    grad_w1 = cache["x"].T @ grad_z1
    grad_b1 = grad_z1.sum(axis=0)

    gradients = {
        "w1": grad_w1,
        "b1": grad_b1,
        "w2": grad_w2,
        "b2": grad_b2,
    }
    return loss, gradients
```

## 12. 参数更新

```python
for name in parameters:
    parameters[name] -= learning_rate * gradients[name]
```

梯度更新前检查：

```python
for name in parameters:
    assert gradients[name].shape == parameters[name].shape
    assert np.isfinite(gradients[name]).all()
```

保存最佳参数时必须 `.copy()`：

```python
best_parameters = {name: value.copy() for name, value in parameters.items()}
```

直接赋值字典会共享底层数组，后续更新可能覆盖“最佳参数”。

## 13. 数值梯度检查

对参数字典中的每个数组逐元素扰动：

```text
numeric = [L(θ+h)-L(θ-h)] / (2h)
```

相对误差：

```python
relative_error = np.linalg.norm(analytic - numeric) / (
    np.linalg.norm(analytic) + np.linalg.norm(numeric) + 1e-12
)
```

建议：

- 只使用 3～5 个样本
- 隐藏层只用 2～4 个单元
- 使用 `float64`
- 避免让 `z1` 正好等于 0，因为 ReLU 在 0 处不可导
- 相对误差目标小于 `1e-5`

## 19. 常见故障

### 所有隐藏单元输出相同

检查是否把 `W1` 全部初始化为零。

### 损失为 NaN

检查 Softmax 稳定性、学习率、标准化和 `log(0)`。

### 梯度检查失败

逐层检查，从 `dlogits` 开始；确认平均因子只除一次，矩阵转置方向正确。

### 训练准确率一直是随机水平

检查标签编码、参数更新、ReLU 激活比例和预测的 `axis`。

### 验证表现不稳定

小数据波动正常。保持划分固定，比较多组随机初始化，并报告均值与波动。
