## 2. 均值、方差（variance）、标准差与范数

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0, 4.0])

print(x.mean())             # 2.5
print(x.var())              # 1.25
print(x.std())              # 1.118...
print(np.linalg.norm(x))    # L2 范数
```

总体方差的计算过程：

```text
mean = 所有元素之和 / 元素个数
var  = 每个元素与均值之差的平方的平均值
std  = sqrt(var)
```

NumPy 统计方法的命名均为英文单词的缩写：

| 方法                  | 全称               | 含义            | 计算方式                                              |
| --------------------- | ------------------ | --------------- | ----------------------------------------------------- |
| `x.mean()`            | mean               | 均值            | `sum(x) / N`                                          |
| `x.var()`             | variance           | 方差            | `sum((x - mean)²) / (N - ddof)`，默认 `ddof=0`        |
| `x.std()`             | standard deviation | 标准差          | `sqrt(var)`，即 `sqrt(sum((x - mean)²) / (N - ddof))` |
| `x.sum()`             | sum                | 求和            | `Σ xi`                                                |
| `x.max()` / `x.min()` | maximum / minimum  | 最大值 / 最小值 | 遍历所有元素取最值                                    |

看到 `var`、`std` 这类缩写，可以直接对应到统计量的英文名。

NumPy 默认使用 `ddof=0`，计算总体方差。统计学中估计样本方差时常用 `ddof=1`：

```python
x.var(ddof=0)  # 总体方差
x.var(ddof=1)  # 样本方差
```

本阶段的特征标准化统一使用 `ddof=0`，与 `StandardScaler` 的常见行为一致。

补充：

### 总体方差与样本方差的区别

两者公式只差分母，但含义不同：

```text
总体方差: var = Σ(xi - mean)² / N        # ddof=0
样本方差: var = Σ(xi - mean)² / (N - 1)  # ddof=1
```

以 `x = [1, 2, 3, 4, 5]`（均值 3）为例，离差平方和为 `10`：

```python
x.var(ddof=0)  # 10/5     = 2.0   总体方差
x.var(ddof=1)  # 10/(5-1) = 2.5   样本方差
```

为什么样本方差要除以 `N - 1`？

用样本均值估计总体均值时已经消耗了 1 个自由度（离差之和恒为 0）。若仍除以 `N`，会系统性低估总体方差；除以 `N - 1` 得到无偏估计（Bessel 校正）。

选用原则：

- 数据本身就是完整总体（如全班成绩）→ `ddof=0`
- 用样本推断总体方差（如抽 50 人估计全省收入）→ `ddof=1`

本阶段的特征标准化关心"当前数据本身"，因此统一使用 `ddof=0`。

### 向量范数

L2 范数表示向量长度：

```text
||x||₂ = sqrt(x₁² + x₂² + ... + xₙ²)
```

```python
vectors = np.array([
    [3.0, 4.0],
    [5.0, 12.0],
])

np.linalg.norm(vectors, axis=1)  # [5.0, 13.0]
```

指定 `axis=1` 表示为每一行计算一个范数。

逐行套用 L2 范数公式 `sqrt(x₁² + x₂²)`：

| 行  | 元素      | 计算过程                     | 结果   |
| --- | --------- | ---------------------------- | ------ |
| 1   | `[3, 4]`  | `sqrt(3² + 4²) = sqrt(25)`   | `5.0`  |
| 2   | `[5, 12]` | `sqrt(5² + 12²) = sqrt(169)` | `13.0` |

最终输出 `[5.0, 13.0]`，正好是两组勾股数（3-4-5 和 5-12-13）。

不同 `axis` 的差异：

```python
np.linalg.norm(vectors)           # 13.928...        全部元素一起算
np.linalg.norm(vectors, axis=0)   # [5.831, 12.369]  每一列一个范数
np.linalg.norm(vectors, axis=1)   # [5.0, 13.0]      每一行一个范数
```

形状推演：

```text
vectors            (2, 2)
axis=1 归并列方向  ↓ 消掉第 1 维
结果形状           (2,)    ← 每行一个标量
```

## 3. 浮点数不是无限精确的

计算机使用有限位数表示浮点数：

```python
print(np.finfo(np.float32))
print(np.finfo(np.float64))
```

重点关注：

- `max`：能表示的最大有限值
- `tiny`：最小正规正数
- `eps`：`1.0` 附近可区分的最小间隔

经典例子：

```python
0.1 + 0.2 == 0.3                 # False
np.isclose(0.1 + 0.2, 0.3)       # True
```

比较浮点计算结果时，通常使用 `np.isclose` 或 `np.allclose`，不要直接使用 `==`。

### dtype 会影响范围

```python
x32 = np.array([100.0], dtype=np.float32)
x64 = np.array([100.0], dtype=np.float64)

np.exp(x32)  # float32 中很容易上溢
np.exp(x64)  # float64 范围更大，但也不是无限大
```

更高精度通常占用更多内存和计算资源；深度学习会在范围、精度、速度和显存之间权衡。

## 4. 四类常见数值问题

### 4.1 上溢

数值超过 dtype 能表示的最大值：

```python
with np.errstate(over="ignore"):
    print(np.exp(1000.0))  # inf
```

### 4.2 下溢

极小的非零值被舍入为 `0`：

```python
print(np.exp(-1000.0))  # 0.0
```

下溢不一定立即报错，但可能让后续的 `log` 或除法出问题。

### 4.3 除零

```python
with np.errstate(divide="ignore", invalid="ignore"):
    print(np.array([1.0, 0.0]) / 0.0)  # [inf, nan]
```

### 4.4 非法函数输入

```python
with np.errstate(divide="ignore", invalid="ignore"):
    print(np.log(0.0))   # -inf
    print(np.log(-1.0))  # nan
```

`np.errstate` 只控制警告显示，不会自动修复问题。真正的解决方法是改写公式、限制输入范围或显式处理边界。

## 5. 数值稳定的 Sigmoid

Sigmoid 定义为：

```text
sigmoid(x) = 1 / (1 + exp(-x))
```

### 5.1 Sigmoid 的含义与用途

- **几何特性**：把任意实数压缩到 (0, 1) 区间，曲线呈"S"形，单调递增，在 `x = 0` 处斜率最大（≈ 0.25）。
  - `x` 很大正数 → `exp(-x) → 0` → sigmoid 趋近 **1**
  - `x` 很大负数 → `exp(-x) → +∞` → sigmoid 趋近 **0**
  - `x = 0` → sigmoid = **0.5**
- **典型用途**：
  1. **二分类输出**：神经网络最后一层把 logits 转成概率 `p ∈ (0, 1)`。
  2. **逻辑回归**：`p = sigmoid(wᵀx)`，再配合交叉熵作为损失函数。
  3. **门控机制**：LSTM / GRU 中的输入门、遗忘门等用 sigmoid 控制信息通过比例。

直接实现：

```python
def naive_sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))
```

当 `x` 是很大的负数时，`exp(-x)` 会上溢。可按正负分支计算：

```python
def stable_sigmoid(x):
    x = np.asarray(x, dtype=np.float64)
    result = np.empty_like(x)

    positive = x >= 0
    result[positive] = 1.0 / (1.0 + np.exp(-x[positive]))

    exp_x = np.exp(x[~positive])
    result[~positive] = exp_x / (1.0 + exp_x)
    return result
```

不要简单写成 `np.where(condition, expression_a, expression_b)` 来规避上溢，因为 NumPy 通常会先计算两个分支，再选择结果。

还可以使用稳定的对数运算：

```python
def stable_sigmoid_compact(x):
    x = np.asarray(x, dtype=np.float64)
    return np.exp(-np.logaddexp(0.0, -x))
```

## 6. 数值稳定的 Softmax

Softmax 把每行 logits 转成概率：

```text
softmax(xᵢ) = exp(xᵢ) / Σⱼ exp(xⱼ)
```

### 6.1 Softmax 的含义与用途

输入一个长度为 `K` 的向量 `x = [x₁, x₂, ..., x_K]`（比如 K 个类别的得分），输出一个长度为 `K` 的概率向量 `p = [p₁, p₂, ..., p_K]`，满足：

1. **非负性**：每个 `pᵢ = exp(xᵢ) / Σⱼ exp(xⱼ) ≥ 0`，因为指数函数恒正。
2. **归一化**：`Σᵢ pᵢ = 1`，所以结果可以解释为"属于每个类的概率"。
3. **保序性**：原 logit 越大 → 指数越大 → 概率越大，相对大小关系不变。
4. **放大差距**：由于指数增长，原本差距不大的 logits 经过 softmax 后会被"拉开"，倾向于"赢家通吃"。

- **典型用途**：
  1. **多分类输出层**：最后一层全连接产生 K 个 logit，用 softmax 转成 K 类概率，再配合交叉熵损失训练。
  2. **注意力机制**：Transformer 把 attention scores 经 softmax 得到归一化的注意力权重（每个 query 对各 key 的关注比例）。
  3. **概率采样**：把任意一组打分转成可被采样的概率分布（如策略梯度中的动作选择）。

- **与 Sigmoid 的对比**：

|      | Sigmoid                         | Softmax                          |
| ---- | ------------------------------- | -------------------------------- |
| 输入 | 标量                            | 向量                             |
| 输出 | 单个 (0,1) 值                   | 一组概率，和为 1                 |
| 适用 | 二分类 / 门控                   | 多分类 / 注意力权重              |
| 关系 | 二分类时 softmax 退化为 sigmoid | sigmoid 是 K=2 时 softmax 的特例 |

直接计算大数的指数会溢出：

```python
logits = np.array([[1000.0, 1001.0, 1002.0]])
```

Softmax 有一个重要性质：为一行中的所有 logits 加减同一个常数，结果不变。因此先减去每行最大值：

```python
def softmax(logits):
    logits = np.asarray(logits, dtype=np.float64)
    shifted = logits - logits.max(axis=-1, keepdims=True)
    exponentials = np.exp(shifted)
    return exponentials / exponentials.sum(axis=-1, keepdims=True)
```

形状变化：

```text
logits               (batch, classes)
每行最大值            (batch, 1)
shifted              (batch, classes)
每行指数和            (batch, 1)
probabilities        (batch, classes)
```

使用 `axis=-1` 可以让函数同时适用于二维和更高维输入，始终在最后一个类别维度上归一化。

## 7. MSE：回归任务的常见损失

均方误差：

```text
MSE = mean((y_true - y_pred)²)
```

```python
def mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=np.float64)
    y_pred = np.asarray(y_pred, dtype=np.float64)
    return float(np.mean((y_true - y_pred) ** 2))
```

性质：

- 预测完全正确时 MSE 为 `0`
- 误差的正负会在平方后消失
- 较大的误差会受到更重惩罚
- MSE 对异常值较敏感

## 8. 交叉熵：分类任务的常见损失

交叉熵（Cross Entropy）用来衡量：

> 模型给出的概率分布，与真实答案的概率分布有多不一致。

在分类任务中，可以先把它理解为：**模型给正确类别的概率越高，交叉熵越小；给正确类别的概率越低，交叉熵越大。**

### 8.1 从一个问题开始理解

假设图片真实类别是“猫”，模型预测：

| 类别 | 真实标签 | 模型预测概率 |
| --- | ---: | ---: |
| 猫 | 1 | 0.70 |
| 狗 | 0 | 0.20 |
| 鸟 | 0 | 0.10 |

真实标签使用 one-hot 表示：

```python
y_true = np.array([1.0, 0.0, 0.0])
probabilities = np.array([0.70, 0.20, 0.10])
```

交叉熵会重点检查模型给“猫”分配的概率：

```text
loss = -log(0.70) ≈ 0.357
```

如果模型把“猫”的概率提高到 `0.95`：

```text
loss = -log(0.95) ≈ 0.051
```

如果模型非常自信地预测错，只给“猫”分配 `0.01`：

```text
loss = -log(0.01) ≈ 4.605
```

因此，交叉熵不仅关心“最终选中了哪个类别”，还关心模型有多自信。

### 8.2 为什么使用负对数

单个正确类别概率 `p` 的损失为：

```text
loss = -log(p)
```

这里使用自然对数。观察几个值：

| 正确类别概率 `p` | `-log(p)` | 含义 |
| ---: | ---: | --- |
| `1.0` | `0.000` | 完全确定且正确，损失为 0 |
| `0.9` | `0.105` | 预测较好，损失很小 |
| `0.5` | `0.693` | 不太确定 |
| `0.1` | `2.303` | 正确类别概率很低 |
| `0.01` | `4.605` | 非常自信地偏离正确答案 |

负对数具有三个有用性质：

1. `p` 越接近 `1`，损失越接近 `0`。
2. `p` 越接近 `0`，损失增长得越快，会重罚自信的错误。
3. 多个样本概率的乘积经过对数后会变成和，便于优化和数值计算。

```text
-log(p₁ × p₂ × p₃) = -log(p₁) - log(p₂) - log(p₃)
```

### 8.3 完整公式在计算什么

真实分布记为 `y`，模型预测分布记为 `p`。单个样本的交叉熵为：

```text
H(y, p) = -Σᵢ yᵢ log(pᵢ)
```

使用 one-hot 标签时：

```text
y = [1, 0, 0]
p = [0.7, 0.2, 0.1]

H(y, p)
= -(1×log(0.7) + 0×log(0.2) + 0×log(0.1))
= -log(0.7)
```

因为错误类别的 `yᵢ` 都是 `0`，它们对应的项会被消掉。因此对于 one-hot 标签：

> 多分类交叉熵等于“正确类别预测概率的负对数”。

对于一批样本，再对每个样本的交叉熵求平均：

```text
CrossEntropy = -mean(Σ y_true × log(probabilities))
```

从概率分布角度看，交叉熵还可以写成：

```text
H(y, p) = H(y) + KL(y || p)
```

训练数据的真实分布 `y` 固定时，`H(y)` 不变。因此最小化交叉熵，也是在让预测分布 `p` 尽量接近真实分布 `y`。第一阶段只需要形成这个直觉，不要求推导 KL 散度。

### 8.4 手算一个批次

假设有两个二分类样本：

```python
y_true = np.array([
    [1.0, 0.0],  # 第一个样本的正确类别是 0
    [0.0, 1.0],  # 第二个样本的正确类别是 1
])

probabilities = np.array([
    [0.9, 0.1],  # 正确类别概率为 0.9
    [0.2, 0.8],  # 正确类别概率为 0.8
])
```

分别计算两个样本：

```text
样本 1：-log(0.9) ≈ 0.105
样本 2：-log(0.8) ≈ 0.223

批次平均：(0.105 + 0.223) / 2 ≈ 0.164
```

用 NumPy 拆开计算：

```python
log_probabilities = np.log(probabilities)
weighted_log_probabilities = y_true * log_probabilities
loss_per_sample = -weighted_log_probabilities.sum(axis=-1)
loss = loss_per_sample.mean()

print(loss_per_sample)  # [0.10536052, 0.22314355]
print(loss)             # 0.164252...
```

形状变化：

```text
y_true、probabilities    (batch, classes)
沿 classes 求和          (batch,)
沿 batch 求平均          ()，得到一个标量
```

### 8.5 one-hot 标签版本

讲义配套练习使用 one-hot 标签：

```python
def cross_entropy(y_true, probabilities):
    y_true = np.asarray(y_true, dtype=np.float64)
    probabilities = np.asarray(probabilities, dtype=np.float64)

    safe_probabilities = np.clip(probabilities, 1e-12, 1.0)
    log_probabilities = np.log(safe_probabilities)
    loss_per_sample = -np.sum(y_true * log_probabilities, axis=-1)

    return float(np.mean(loss_per_sample))
```

这个实现要求：

- `y_true.shape == probabilities.shape`
- 每一行 `y_true` 是一个 one-hot 标签
- 每一行 `probabilities` 的元素位于 `[0, 1]`
- 每一行预测概率之和约等于 `1`

可以在学习阶段加入检查：

```python
assert y_true.shape == probabilities.shape
assert np.allclose(probabilities.sum(axis=-1), 1.0)
assert np.all((probabilities >= 0.0) & (probabilities <= 1.0))
```

### 8.6 类别编号版本

真实项目通常不会真的创建巨大的 one-hot 矩阵，而是直接保存正确类别编号：

```python
labels = np.array([0, 2])

probabilities = np.array([
    [0.7, 0.2, 0.1],
    [0.1, 0.2, 0.7],
])
```

使用高级索引直接取出每个样本的正确类别概率：

```python
batch_indices = np.arange(len(labels))
correct_probabilities = probabilities[batch_indices, labels]
loss = -np.log(correct_probabilities).mean()

print(correct_probabilities)  # [0.7, 0.7]
print(loss)                   # 约 0.357
```

one-hot 版本和类别编号版本表达的是同一件事，只是标签存储方式不同。

### 8.7 交叉熵与 Softmax 的关系

模型线性层通常先输出 logits：

```python
logits = np.array([[2.0, 1.0, -1.0]])
```

logits 不是概率：它可以是负数，元素之和也不需要等于 `1`。典型计算流程是：

```text
模型输出 logits
      ↓
Softmax 转成 probabilities
      ↓
交叉熵检查正确类别概率
      ↓
对批次求平均得到 loss
```

```python
probabilities = softmax(logits)
loss = cross_entropy(y_true, probabilities)
```

不要把原始 logits 直接传入上面的概率版本 `cross_entropy`，因为对负 logits 取对数没有意义。

### 8.8 为什么实际训练常把 Softmax 和交叉熵合并

先计算概率、再取对数，会出现两个问题：

1. 极小概率可能下溢为 `0`，随后 `log(0)` 得到 `-inf`。
2. 先算 `exp` 再算 `log`，会产生不必要的数值误差。

概率版本使用下面的保护：

```python
safe_probabilities = np.clip(probabilities, 1e-12, 1.0)
```

`clip` 适合当前阶段理解边界处理，但实际训练更常直接从 logits 计算交叉熵。类别编号版本可以写成：

```python
def cross_entropy_from_logits(labels, logits):
    labels = np.asarray(labels, dtype=np.int64)
    logits = np.asarray(logits, dtype=np.float64)

    shifted = logits - logits.max(axis=-1, keepdims=True)
    log_sum_exp = np.log(np.exp(shifted).sum(axis=-1))

    batch_indices = np.arange(len(labels))
    correct_logits = shifted[batch_indices, labels]
    loss_per_sample = log_sum_exp - correct_logits

    return float(loss_per_sample.mean())
```

这里没有先生成概率再取对数，数值更加稳定。后续使用 PyTorch 时，通常直接把原始 logits 传给 `CrossEntropyLoss`，不需要自己先调用 Softmax。

### 8.9 二分类、多分类与多标签分类

不同任务使用的组合不同：

| 任务 | 模型输出 | 常用损失 |
| --- | --- | --- |
| 二分类：两个类别互斥 | 一个 logit，经 Sigmoid | 二元交叉熵 |
| 多分类：多个类别只能选一个 | K 个 logits，经 Softmax | 多分类交叉熵 |
| 多标签：多个标签可以同时成立 | 每个标签一个 logit，分别经 Sigmoid | 逐标签二元交叉熵 |

二元交叉熵公式为：

```text
BCE = -(y log(p) + (1-y) log(1-p))
```

不要对多标签任务使用一次 Softmax，因为 Softmax 会强制所有标签概率之和为 `1`，不允许多个标签同时具有高概率。

### 8.10 在大语言模型中如何使用

语言模型会对每个位置预测“下一个 Token”：

```text
logits 形状：(batch, sequence, vocabulary_size)
labels 形状：(batch, sequence)
```

假设词表有 50,000 个 Token，某个位置的正确 Token 编号是 `42`。交叉熵会从该位置的 50,000 个预测结果中，取出编号 `42` 对应的概率并计算负对数。

训练时通常还会：

- 忽略 Padding Token 对应的位置
- 对所有有效 Token 的损失求平均
- 直接从 logits 计算稳定的交叉熵
- 使用 `exp(平均交叉熵)` 得到困惑度（Perplexity）

例如平均交叉熵为 `2.303`：

```python
perplexity = np.exp(2.303)  # 约为 10
```

可以粗略理解为：模型在每个位置上像是在大约 10 个候选 Token 之间犹豫。困惑度越低通常越好，但只能在相同数据处理、词表和评测设置下比较。

### 8.11 常见错误

1. 把 logits 当作概率直接取对数。
2. 忘记 Softmax 应沿类别维度计算。
3. one-hot 标签和概率数组形状不一致。
4. 忘记对类别维度求和，导致返回的不是每个样本一个损失。
5. 忘记对批次求平均，最终返回一个向量而不是标量。
6. 没有处理 `log(0)`。
7. 在 PyTorch 的 `CrossEntropyLoss` 前再次手动调用 Softmax。
8. 把多分类和多标签分类混为一谈。

### 8.12 小结

记住下面这一条主线即可：

```text
交叉熵 = 正确类别预测概率的负对数，再对样本求平均
```

正确类别概率越高，交叉熵越小；正确类别概率越低，交叉熵越大。Softmax 负责把 logits 转成概率，交叉熵负责评价这组概率对真实答案有多好。

## 9. 用性质测试数学函数

只检查一个固定输入不够。应同时验证函数必须满足的性质：

### Sigmoid

- 输出范围在 `[0, 1]`
- `sigmoid(0) == 0.5`
- 输入单调增大时输出不减小
- 极端输入不产生 `NaN`

### Softmax

- 每行概率之和约等于 `1`
- 所有概率处于 `[0, 1]`
- 输出形状与输入一致
- 每行 logits 加同一个常数后结果不变
- 极大或极小输入不产生 `NaN`

### MSE 与交叉熵

- 完全正确的回归预测使 MSE 等于 `0`
- MSE 不为负数
- 正确类别概率越低，交叉熵越大
- 概率中出现 `0` 时仍返回有限结果

## 10. 与大模型的联系

- Sigmoid 常用于二分类、多标签分类和门控结构。
- Softmax 把分类 logits 或 Attention 分数转换为概率分布。
- 交叉熵是语言模型“预测下一个 Token”时的核心损失。
- 数值稳定性问题会在低精度训练、大批量计算和极端 logits 中被放大。
- Transformer 的 Attention 也会在 Softmax 前进行缩放，并对 Mask 位置加入极小值。

## 11. 自测题

1. 为什么 `softmax([1000, 1001])` 不能直接计算指数？
2. 为什么每行 logits 减去最大值不会改变 Softmax？
3. `np.clip(probabilities, 1e-12, 1.0)` 解决了什么问题？
4. 为什么浮点结果通常使用 `np.allclose` 比较？
5. 当正确类别概率从 `0.9` 降到 `0.1` 时，交叉熵如何变化？

参考答案：

1. `exp(1000)` 超过浮点范围，会产生 `inf`。
2. 分子和分母都乘上同一个指数因子，该因子会约掉。
3. 避免 `log(0)` 产生负无穷。
4. 浮点表示和运算存在舍入误差。
5. 交叉熵显著增大，模型受到更重惩罚。

## 12. 易错点

1. 用 `==` 比较复杂浮点计算结果。
2. 以为换成 `float64` 就不会发生上溢。
3. Softmax 减去整个矩阵的全局最大值，而不是每行最大值。
4. 聚合后忘记 `keepdims=True`，导致广播方向错误。
5. 直接计算 `np.log(0)`。
6. 把类别编号当作 one-hot 标签代入 one-hot 版本交叉熵。
7. 只验证固定答案，没有验证概率和、有限性与平移不变性。
