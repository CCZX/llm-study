## 2. 均值、方差、标准差与范数

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0, 4.0])

print(x.mean())             # 2.5
print(x.var())              # 1.25
print(x.std())              # 1.118...
print(np.linalg.norm(x))    # L2 范数
```

总体方差的计算过程：

```text
mean = 所有元素之和 / 元素个数
var  = 每个元素与均值之差的平方的平均值
std  = sqrt(var)
```

NumPy 默认使用 `ddof=0`，计算总体方差。统计学中估计样本方差时常用 `ddof=1`：

```python
x.var(ddof=0)  # 总体方差
x.var(ddof=1)  # 样本方差
```

本阶段的特征标准化统一使用 `ddof=0`，与 `StandardScaler` 的常见行为一致。

### 向量范数

L2 范数表示向量长度：

```text
||x||₂ = sqrt(x₁² + x₂² + ... + xₙ²)
```

```python
vectors = np.array([
    [3.0, 4.0],
    [5.0, 12.0],
])

np.linalg.norm(vectors, axis=1)  # [5.0, 13.0]
```

指定 `axis=1` 表示为每一行计算一个范数。

## 3. 浮点数不是无限精确的

计算机使用有限位数表示浮点数：

```python
print(np.finfo(np.float32))
print(np.finfo(np.float64))
```

重点关注：

- `max`：能表示的最大有限值
- `tiny`：最小正规正数
- `eps`：`1.0` 附近可区分的最小间隔

经典例子：

```python
0.1 + 0.2 == 0.3                 # False
np.isclose(0.1 + 0.2, 0.3)       # True
```

比较浮点计算结果时，通常使用 `np.isclose` 或 `np.allclose`，不要直接使用 `==`。

### dtype 会影响范围

```python
x32 = np.array([100.0], dtype=np.float32)
x64 = np.array([100.0], dtype=np.float64)

np.exp(x32)  # float32 中很容易上溢
np.exp(x64)  # float64 范围更大，但也不是无限大
```

更高精度通常占用更多内存和计算资源；深度学习会在范围、精度、速度和显存之间权衡。

## 4. 四类常见数值问题

### 4.1 上溢

数值超过 dtype 能表示的最大值：

```python
with np.errstate(over="ignore"):
    print(np.exp(1000.0))  # inf
```

### 4.2 下溢

极小的非零值被舍入为 `0`：

```python
print(np.exp(-1000.0))  # 0.0
```

下溢不一定立即报错，但可能让后续的 `log` 或除法出问题。

### 4.3 除零

```python
with np.errstate(divide="ignore", invalid="ignore"):
    print(np.array([1.0, 0.0]) / 0.0)  # [inf, nan]
```

### 4.4 非法函数输入

```python
with np.errstate(divide="ignore", invalid="ignore"):
    print(np.log(0.0))   # -inf
    print(np.log(-1.0))  # nan
```

`np.errstate` 只控制警告显示，不会自动修复问题。真正的解决方法是改写公式、限制输入范围或显式处理边界。

## 5. 数值稳定的 Sigmoid

Sigmoid 定义为：

```text
sigmoid(x) = 1 / (1 + exp(-x))
```

直接实现：

```python
def naive_sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))
```

当 `x` 是很大的负数时，`exp(-x)` 会上溢。可按正负分支计算：

```python
def stable_sigmoid(x):
    x = np.asarray(x, dtype=np.float64)
    result = np.empty_like(x)

    positive = x >= 0
    result[positive] = 1.0 / (1.0 + np.exp(-x[positive]))

    exp_x = np.exp(x[~positive])
    result[~positive] = exp_x / (1.0 + exp_x)
    return result
```

不要简单写成 `np.where(condition, expression_a, expression_b)` 来规避上溢，因为 NumPy 通常会先计算两个分支，再选择结果。

还可以使用稳定的对数运算：

```python
def stable_sigmoid_compact(x):
    x = np.asarray(x, dtype=np.float64)
    return np.exp(-np.logaddexp(0.0, -x))
```

## 6. 数值稳定的 Softmax

Softmax 把每行 logits 转成概率：

```text
softmax(xᵢ) = exp(xᵢ) / Σⱼ exp(xⱼ)
```

直接计算大数的指数会溢出：

```python
logits = np.array([[1000.0, 1001.0, 1002.0]])
```

Softmax 有一个重要性质：为一行中的所有 logits 加减同一个常数，结果不变。因此先减去每行最大值：

```python
def softmax(logits):
    logits = np.asarray(logits, dtype=np.float64)
    shifted = logits - logits.max(axis=-1, keepdims=True)
    exponentials = np.exp(shifted)
    return exponentials / exponentials.sum(axis=-1, keepdims=True)
```

形状变化：

```text
logits               (batch, classes)
每行最大值            (batch, 1)
shifted              (batch, classes)
每行指数和            (batch, 1)
probabilities        (batch, classes)
```

使用 `axis=-1` 可以让函数同时适用于二维和更高维输入，始终在最后一个类别维度上归一化。

## 7. MSE：回归任务的常见损失

均方误差：

```text
MSE = mean((y_true - y_pred)²)
```

```python
def mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=np.float64)
    y_pred = np.asarray(y_pred, dtype=np.float64)
    return float(np.mean((y_true - y_pred) ** 2))
```

性质：

- 预测完全正确时 MSE 为 `0`
- 误差的正负会在平方后消失
- 较大的误差会受到更重惩罚
- MSE 对异常值较敏感

## 8. 交叉熵：分类任务的常见损失

使用 one-hot 标签时：

```text
CrossEntropy = -mean(Σ y_true × log(probabilities))
```

```python
def cross_entropy(y_true, probabilities):
    y_true = np.asarray(y_true, dtype=np.float64)
    probabilities = np.asarray(probabilities, dtype=np.float64)
    safe_probabilities = np.clip(probabilities, 1e-12, 1.0)
    return float(-np.mean(np.sum(y_true * np.log(safe_probabilities), axis=-1)))
```

使用 `clip` 是为了避免 `log(0)`。正确类别概率越接近 `1`，损失越小；越接近 `0`，损失越大：

```python
-np.log(0.9)  # 约 0.105
-np.log(0.5)  # 约 0.693
-np.log(0.1)  # 约 2.303
```

注意：真正训练分类器时，最好直接从 logits 计算 log-softmax 和交叉熵，以减少中间概率舍入带来的问题。第一阶段先掌握概率版本。

## 9. 用性质测试数学函数

只检查一个固定输入不够。应同时验证函数必须满足的性质：

### Sigmoid

- 输出范围在 `[0, 1]`
- `sigmoid(0) == 0.5`
- 输入单调增大时输出不减小
- 极端输入不产生 `NaN`

### Softmax

- 每行概率之和约等于 `1`
- 所有概率处于 `[0, 1]`
- 输出形状与输入一致
- 每行 logits 加同一个常数后结果不变
- 极大或极小输入不产生 `NaN`

### MSE 与交叉熵

- 完全正确的回归预测使 MSE 等于 `0`
- MSE 不为负数
- 正确类别概率越低，交叉熵越大
- 概率中出现 `0` 时仍返回有限结果

## 10. 与大模型的联系

- Sigmoid 常用于二分类、多标签分类和门控结构。
- Softmax 把分类 logits 或 Attention 分数转换为概率分布。
- 交叉熵是语言模型“预测下一个 Token”时的核心损失。
- 数值稳定性问题会在低精度训练、大批量计算和极端 logits 中被放大。
- Transformer 的 Attention 也会在 Softmax 前进行缩放，并对 Mask 位置加入极小值。

2. 为什么每行 logits 减去最大值不会改变 Softmax？
3. `np.clip(probabilities, 1e-12, 1.0)` 解决了什么问题？
4. 为什么浮点结果通常使用 `np.allclose` 比较？
5. 当正确类别概率从 `0.9` 降到 `0.1` 时，交叉熵如何变化？

参考答案：

1. `exp(1000)` 超过浮点范围，会产生 `inf`。
2. 分子和分母都乘上同一个指数因子，该因子会约掉。
3. 避免 `log(0)` 产生负无穷。
4. 浮点表示和运算存在舍入误差。
5. 交叉熵显著增大，模型受到更重惩罚。

## 12. 易错点

1. 用 `==` 比较复杂浮点计算结果。
2. 以为换成 `float64` 就不会发生上溢。
3. Softmax 减去整个矩阵的全局最大值，而不是每行最大值。
4. 聚合后忘记 `keepdims=True`，导致广播方向错误。
5. 直接计算 `np.log(0)`。
6. 把类别编号当作 one-hot 标签代入 one-hot 版本交叉熵。
7. 只验证固定答案，没有验证概率和、有限性与平移不变性。
