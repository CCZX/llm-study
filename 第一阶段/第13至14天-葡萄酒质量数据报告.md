这是第二周的综合项目。目标不是训练复杂模型，而是独立走完一次可复现的数据分析流程：


## 2. 数据字段

数据包含 11 个理化特征和 1 个质量评分：

| 字段 | 含义 | 类型 |
| --- | --- | --- |
| `fixed acidity` | 固定酸度 | 连续数值 |
| `volatile acidity` | 挥发性酸度 | 连续数值 |
| `citric acid` | 柠檬酸 | 连续数值 |
| `residual sugar` | 残糖 | 连续数值 |
| `chlorides` | 氯化物 | 连续数值 |
| `free sulfur dioxide` | 游离二氧化硫 | 连续数值 |
| `total sulfur dioxide` | 总二氧化硫 | 连续数值 |
| `density` | 密度 | 连续数值 |
| `pH` | 酸碱度 | 连续数值 |
| `sulphates` | 硫酸盐 | 连续数值 |
| `alcohol` | 酒精度 | 连续数值 |
| `quality` | 感官质量评分 | 离散整数目标 |

合并红、白葡萄酒时，自己增加 `wine_type` 列，避免丢失来源类别。

## 10. 第七步：划分训练、验证和测试集

使用固定随机种子，建议比例为 `70% / 15% / 15%`：

```python
rng = np.random.default_rng(42)
indices = rng.permutation(len(wine_clean))

n_train = int(len(indices) * 0.70)
n_valid = int(len(indices) * 0.15)

train_indices = indices[:n_train]
valid_indices = indices[n_train : n_train + n_valid]
test_indices = indices[n_train + n_valid :]

train = wine_clean.iloc[train_indices].copy()
valid = wine_clean.iloc[valid_indices].copy()
test = wine_clean.iloc[test_indices].copy()
```

验证：

```python
assert len(train) + len(valid) + len(test) == len(wine_clean)
assert set(train.index).isdisjoint(valid.index)
assert set(train.index).isdisjoint(test.index)
assert set(valid.index).isdisjoint(test.index)
```

额外比较三个集合的 `quality` 和 `wine_type` 分布。如果差异很大，在局限中说明，并在后续学习分层划分。

## 11. 第八步：只用训练集统计量标准化

选择 11 个理化数值特征，不要标准化 `quality` 和 `wine_type`：

```python
feature_columns = [
    column
    for column in wine_clean.columns
    if column not in {"quality", "wine_type"}
]

x_train = train[feature_columns].to_numpy(dtype=np.float64)
x_valid = valid[feature_columns].to_numpy(dtype=np.float64)
x_test = test[feature_columns].to_numpy(dtype=np.float64)

train_mean = x_train.mean(axis=0, keepdims=True)
train_std = x_train.std(axis=0, keepdims=True)
safe_std = np.where(train_std == 0, 1.0, train_std)

x_train_scaled = (x_train - train_mean) / safe_std
x_valid_scaled = (x_valid - train_mean) / safe_std
x_test_scaled = (x_test - train_mean) / safe_std
```

验证：

```python
assert np.allclose(x_train_scaled.mean(axis=0), 0.0, atol=1e-7)
assert np.allclose(x_train_scaled.std(axis=0), 1.0, atol=1e-7)
assert np.isfinite(x_train_scaled).all()
assert np.isfinite(x_valid_scaled).all()
assert np.isfinite(x_test_scaled).all()
```

验证集和测试集标准化后的均值不需要等于 `0`，因为它们必须使用训练集统计量。

## 12. 第九步：撰写发现与局限

每条发现使用下面的结构：

```text
发现：具体描述方向、差异或分布。
证据：给出统计量、样本数或对应图表。
解释：提出一种合理解释，明确它只是解释而非事实。
边界：说明该结论适用的样本和不能证明的内容。
```

避免空泛表述：

```text
差：酒精度对质量有影响。
好：在本数据集中，较高质量组的酒精度中位数更高；但这是观察性相关，不能证明提高酒精度会导致质量上升。
```

局限至少覆盖两类：

- 数据来自特定葡萄酒产区与生产条件，外推范围有限
- 质量评分具有主观性，且评分分布不均衡
- 重复记录的业务含义不完全明确
- 仅分析相关关系，没有控制混杂变量
- 随机划分未严格保证评分与酒类型分层
- 异常值规则可能把真实的极端样本标记为异常
