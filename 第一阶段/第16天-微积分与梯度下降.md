## 2. 导数表示局部变化率

对于函数：

```text
f(x) = x²
```

导数为：

```text
f'(x) = 2x
```

在 `x=3` 时，导数是 `6`。含义是：当 `x` 在 3 附近增加一个很小的量 `Δx`，函数值大约增加 `6Δx`。

```text
f(3 + Δx) ≈ f(3) + 6Δx
```

例如 `Δx=0.01`：

```python
f = lambda x: x**2

actual_change = f(3.01) - f(3.0)  # 0.0601
linear_approx = 6.0 * 0.01         # 0.06
```

变化足够小时，线性近似会很准确。

## 3. 常用求导规则

| 原函数 | 导数 |
| --- | --- |
| 常数 `c` | `0` |
| `x` | `1` |
| `xⁿ` | `n xⁿ⁻¹` |
| `eˣ` | `eˣ` |
| `log(x)` | `1/x` |
| `f(x)+g(x)` | `f'(x)+g'(x)` |
| `c f(x)` | `c f'(x)` |

例子：

```text
f(x) = 3x² + 2x + 5
f'(x) = 6x + 2
```

本阶段重点是能读懂训练代码中的梯度，不要求完成大量符号积分。

## 4. 最小值与导数

考虑：

```text
f(x) = (x - 3)²
f'(x) = 2(x - 3)
```

- `x < 3` 时，导数为负，向右移动会让函数下降。
- `x > 3` 时，导数为正，向左移动会让函数下降。
- `x = 3` 时，导数为 0，函数达到最小值。

导数为 0 是驻点的必要线索，但不保证一定是最小值，也可能是最大值或更复杂的平坦点。

## 5. 偏导数和梯度

多变量函数：

```text
f(x, y) = x² + 3y²
```

分别只改变一个变量：

```text
∂f/∂x = 2x
∂f/∂y = 6y
```

把所有偏导数组成一个向量，就是梯度：

```text
∇f(x, y) = [2x, 6y]
```

在 `(x, y)=(2, 1)`：

```text
∇f(2, 1) = [4, 6]
```

梯度指向函数上升最快的方向，负梯度指向局部下降最快的方向。

机器学习中的参数可能有上百万甚至上百亿个；梯度与参数具有相同的形状，每个元素表示损失对对应参数的局部敏感度。

## 6. 链式法则

复合函数：

```text
u = 3x + 1
f = u²
```

链式法则：

```text
df/dx = df/du × du/dx
      = 2u × 3
      = 6(3x + 1)
```

在 `x=2` 时：

```text
u = 7
df/dx = 2×7×3 = 42
```

可以把它画成计算图：

```text
x ──×3──> 3x ──+1──> u ──平方──> f
```

反向传播就是从最终损失开始，沿计算图反向应用链式法则，把上游梯度乘上每一步的局部导数。

## 7. 有限差分近似导数

前向差分：

```text
f'(x) ≈ [f(x+h) - f(x)] / h
```

中心差分通常更准确：

```text
f'(x) ≈ [f(x+h) - f(x-h)] / (2h)
```

```python
def numerical_derivative(function, x, h=1e-5):
    return (function(x + h) - function(x - h)) / (2.0 * h)

f = lambda x: (x - 3.0) ** 2

print(numerical_derivative(f, 5.0))  # 接近 4
print(2.0 * (5.0 - 3.0))            # 解析导数为 4
```

`h` 太大会造成近似误差，太小会受到浮点舍入误差影响。`1e-4` 到 `1e-6` 常用于基础梯度检查，但不是所有问题的固定最优值。

## 8. 梯度下降

梯度下降更新规则：

```text
参数新值 = 参数旧值 - 学习率 × 梯度
```

优化 `f(x)=(x-3)²`：

```python
def gradient(x):
    return 2.0 * (x - 3.0)

x = 0.0
learning_rate = 0.1

for step in range(30):
    x = x - learning_rate * gradient(x)
```

因为使用负梯度方向，`x` 会逐渐靠近最小值 `3`。

### 8.1 学习率的影响

- 太小：每步变化很小，训练缓慢。
- 合适：稳定而快速地靠近低损失区域。
- 太大：越过最小值反复震荡，甚至发散。

对这个二次函数：

```text
x_new - 3 = (1 - 2×learning_rate)(x_old - 3)
```

当学习率是 `0.1` 时，距离每步乘 `0.8`；当学习率是 `1.1` 时，距离每步乘 `-1.2`，绝对值不断增大，因此发散。

## 10. 线性回归的 MSE 梯度

模型：

```text
y_hat = X @ w + b
```

其中：

```text
X      (samples, features)
w      (features,)
b      ()
y_hat  (samples,)
```

损失：

```text
L = mean((y_hat - y)²)
```

令：

```text
errors = y_hat - y
```

解析梯度：

```text
dL/dw = (2/N) Xᵀ @ errors
dL/db = 2 mean(errors)
```

NumPy 实现：

```python
def mse_gradients(x, y, w, b):
    predictions = x @ w + b
    errors = predictions - y
    sample_count = len(x)

    grad_w = (2.0 / sample_count) * (x.T @ errors)
    grad_b = 2.0 * errors.mean()
    return grad_w, float(grad_b)
```

形状检查：

```text
X.T                (features, samples)
errors             (samples,)
X.T @ errors       (features,)
grad_w             与 w 形状相同
grad_b             与 b 一样是标量
```

## 11. 梯度检查

解析梯度来自公式推导；数值梯度来自有限差分。两者接近，说明实现大概率正确。

对向量参数逐元素检查：

```python
def numerical_gradient(function, parameters, h=1e-5):
    gradient = np.zeros_like(parameters, dtype=np.float64)

    for index in range(parameters.size):
        positive = parameters.copy()
        negative = parameters.copy()
        positive[index] += h
        negative[index] -= h
        gradient[index] = (function(positive) - function(negative)) / (2 * h)

    return gradient
```

比较时使用相对误差或 `np.allclose`：

```python
np.allclose(analytic_gradient, numeric_gradient, rtol=1e-4, atol=1e-6)
```

梯度检查很慢，只适合小数据和少量参数，不在正式训练的每一步执行。

## 12. 优化与泛化不是一回事

梯度下降直接降低的是训练目标。训练损失下降只说明参数更适合训练数据，不保证在未见数据上表现更好。

```text
优化问题：怎样降低训练损失？
泛化问题：模型在新样本上是否仍然有效？
```

因此训练时还需要验证集、正则化、早停和合适的模型复杂度。第 18 天会系统学习这套流程。

## 13. 易错点

1. 把函数值和导数值混为一谈。
2. 认为导数为 0 就一定是最小值。
3. 忘记梯度下降要减去梯度。
4. 链式法则漏乘某一层的局部导数。
5. `grad_w` 的形状与 `w` 不一致。
6. 数值差分的 `h` 过大或过小。
7. 梯度检查时直接修改原参数，导致后续结果污染。
8. 只看训练损失下降，就认为模型一定泛化良好。
